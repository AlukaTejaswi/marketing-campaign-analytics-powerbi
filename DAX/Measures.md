# UrbanCart Marketing Analytics — DAX Measures

This document contains the key DAX measures used in the UrbanCart Marketing Campaign Performance Analytics Power BI project.

The measures are used to analyse marketing investment, revenue, funnel performance, campaign efficiency, customer acquisition and return on marketing investment.

---


## Total Spend

``` dax
Total Spend =
SUM(Fact_Marketing[Spend])
```
Description
Calculates the total marketing spend across the selected filter context.

## Total Revenue

``` dax
Total Revenue =
SUM(Fact_Marketing[Revenue])
```
Description
Calculates the total revenue attributed to marketing activity.

## Total Impressions

``` dax
Total Impressions =
SUM(Fact_Marketing[Impressions])
```
Description
Calculates the total number of times marketing content or advertisements were displayed.

Impressions represent the top of the marketing funnel and are used to calculate CTR.

## Total Clicks

``` dax
Total Clicks =
SUM(Fact_Marketing[Clean_Clicks])
```
Description
Calculates the total number of clicks generated by marketing activity.

Clicks represent user engagement after an impression and are used to calculate CTR, Conversion Rate and CPC.

## Total Leads

``` dax
Total Leads =
SUM(Fact_Marketing[Leads])
```
Description
Calculates the total number of leads generated through marketing activity.

Leads represent users who have progressed further into the marketing funnel after initial engagement.

## Total Conversions

``` dax
Total Conversions =
SUM(Fact_Marketing[Conversions])
```
Description
Calculates the total number of conversions generated by marketing activity.

Conversions represent the desired business outcome measured in the dataset.

## New Customers

``` dax
New Customers =
SUM(Fact_Marketing[New_Customers])
```

Description
Calculates the total number of new customers associated with marketing activity.

This measure supports customer acquisition analysis and helps distinguish new-customer acquisition from retention and reactivation activity.

## Marketing Funnel Metrics

### CTR — Click-Through Rate

``` dax
CTR % =
DIVIDE([Total Clicks], [Total Impressions], 0)
```

Description
Measures the percentage of impressions that result in clicks, indicating the level of engagement with marketing content.

### Conversion Rate

``` dax
Conversion Rate % =
DIVIDE([Total Conversions], [Total Clicks], 0)
```

Description
Measures the percentage of clicks that result in conversions, indicating how effectively traffic is converted into desired outcomes.

## Cost Efficiency Metrics

## CPC — Cost Per Click

``` dax
CPC =
DIVIDE([Total Spend], [Total Clicks], 0)
```

Description
Measures the average marketing cost required to generate one click.

### CPA — Cost Per Acquisition

``` dax
CPA =
DIVIDE([Total Spend], [Total Conversions], 0)
```

Description
Measures the average marketing cost required to generate one conversion.

## Return Metrics

## ROAS — Return on Advertising Spend

``` dax
ROAS =
DIVIDE([Total Revenue], [Total Spend], 0)
```

Description
Measures how much revenue UrbanCart generates for every $1 spent on marketing.

## ROI — Return on Investment

``` dax
ROI =
DIVIDE([Total Revenue] - [Total Spend], [Total Spend], 0)
```

Description
Measures the return after subtracting marketing spend from attributed revenue, relative to the marketing investment.

## Measure Summary

| # | Measure | Formula / Logic | Format |
|---:|---|---|---|
| 1 | Total Spend | Sum of Clean Spend | Currency |
| 2 | Total Revenue | Sum of Clean Revenue | Currency |
| 3 | Total Impressions | Sum of Impressions | Number |
| 4 | Total Clicks | Sum of Clean Clicks | Number |
| 5 | Total Leads | Sum of Leads | Number |
| 6 | Total Conversions | Sum of Clean Conversions | Number |
| 7 | New Customers | Sum of New Customers | Number |
| 8 | CTR | Clicks ÷ Impressions | Percentage |
| 9 | Conversion Rate | Conversions ÷ Clicks | Percentage |
| 10 | CPC | Spend ÷ Clicks | Currency |
| 11 | CPA | Spend ÷ Conversions | Currency |
| 12 | ROAS | Revenue ÷ Spend | Decimal / x |
| 13 | ROI | (Revenue − Spend) ÷ Spend | Percentage |
